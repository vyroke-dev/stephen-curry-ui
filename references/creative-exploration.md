# Creative Exploration · Image-Only

After evidence-based research, call actual built-in image generation to produce all seven Design System visual boards first. Obtain visual approval. Then generate three distinct full-page visual concept sets, desktop and mobile, using the same approved board version.

**No code-generated UI design:** not HTML/CSS, browser screenshots of code mockups, React, SVG, Python, code-based design explorers or text-only designs. Implementation may begin only after the image concepts are approved.

See [Image-Only Design Protocol](image-only-design-pipeline.md).
