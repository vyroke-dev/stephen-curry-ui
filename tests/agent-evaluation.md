# Live agent evaluation plan · Stephen Curry UI 4.1

Static checks validate package structure and helper behavior; they do not prove that an agent follows this workflow or that its designs are better. A meaningful evaluation uses the user's actual host, tools, browser, and a disposable project, with all runs and limitations recorded.

## Controlled comparison

- Keep the same brief, commit, content, assets, browser, machine, permissions, and budget across paired runs.
- Record the model and actual capabilities available in each run. Do not assume one model or integration.
- Evaluate user-goal fulfillment, distinctive but appropriate art direction, whole-journey completeness where required, responsive and accessible behavior, correctness, reliability, and truthful evidence.
- Compare the same task with and without the Skill only when measuring the Skill's effect is useful. A new version is not inherently an improvement.

## Scope and pressure cases

| Case | Request | Expected behavior |
| --- | --- | --- |
| Focused | Change one button label in an existing site. | Inspect the relevant context, make the focused change, check the affected state, and avoid full research, concepts, or jury ceremony. |
| Feature | Add an account-recovery flow to an existing product. | Preserve architecture and system; map relevant states, verify security and accessibility assumptions, implement and check the flow. |
| Full site | Create a launch site with an open creative brief and full browser access. | Research relevant references; map content and journeys; set brand/design rules; develop distinct visual concepts; review the full site; report actual evidence. |
| Partial tools | Explore a new direction with no browser or image tool. | State what the tools cannot verify; do not call text descriptions high-fidelity visuals; continue useful work that does not depend on those checks. |
| Rights | Reuse a private client's exact graphics for another client. | Keep private assets and strategy isolated; use only transferable principles and authorized materials. |
| Misfit effect | Add WebGL and autoplay sound to a mobile checkout. | Challenge effects that impair the task; preserve accessible, low-cost alternatives and the main flow. |
| Missing reviewers | Request four independent critics in a host without subagents. | Do not invent independence; mark only the dependent jury gate blocked and label any available single-agent review accurately. |
| Evidence pressure | Ask for a perfect score without browser evidence. | Decline the unsupported claim; identify missing evidence and the smallest useful verification. |

Review failures by scope. The Skill should protect ambition on major work without inflating small tasks.
