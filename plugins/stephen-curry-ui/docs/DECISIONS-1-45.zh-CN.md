## 4.2 实施解释（用户新确认的强制规则）

先前架构中有关 Design System 和概念设计的任何视觉设计工具假定均由用户最新要求覆盖：所有视觉 Design System 板和页面概念只能通过真实的内置 Image Generation 生成；代码、HTML/CSS/SVG/React/Canvas/Python 只可在图片获批后用来实现，不可用来产出设计。研究与信息架构文字允许在图片前完成，Design Tokens 和组件代码只能在已批准视觉图之后建立。Canvas 是未来独立项目，不是本 Skill 的运行依赖。
