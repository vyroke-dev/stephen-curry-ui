# Art-Directed Assets and Motion

1. Establish the intended image, illustration, 3D, or video style from the brand and actual content. Do not add imagery or effects merely to fill space.
2. Choose assets by fit: user-supplied and rights-cleared materials, original code or illustration, or a media tool that is actually available and authorized. Never assume GPT Image, Higgsfield, or another provider is connected.
3. Do not incur a cost or use a credit without the user's authorization. Track provenance, rights, intended use, paths, file size, review status, and known generation limits for assets that ship.
4. Use bespoke motion or 3D when it improves the story or task. Respect reduced motion, keyboard and touch alternatives, interruption, performance budgets, and graceful fallback.
5. Validate animated behavior through actual playback or browser observation. A still image does not establish motion quality or responsiveness.
6. Get approval for a consequential brand or system change when it was not already authorized. Keep routine implementation within the established direction.
