# Image-Only Website Concept Exploration

1. Verify seven **genuine image-generated** Design System boards, their recorded provenance and the user's approval. No board approval means no formal page concept work.
2. Discover and call a **real available built-in image-generation tool**. If unavailable mark `IMAGE_GENERATION_BLOCKED`; provide prompts for a supported external ChatGPT image-generation handoff, never implement visuals in code instead.
3. Generate three substantively distinct website concept sets following the **same approved visual Design System**: each includes authentic desktop and mobile raster image compositions with entry, middle and CTA coverage. Distinguish composition, visual rhythm, narrative, art direction and UX, not mere color variations.
4. Save generated original images, prompts, revisions, actual tool outputs and references; visually inspect for errors and compare against approved boards.
5. Four independently executed agents review frozen images. If independent agent execution unavailable, explicitly mark that gate blocked. Obtain actual approval for the chosen image set.
6. Only now pass the approved image references and design decisions to coding agent for **implementation**, never treat its code or screenshots as visual design concepts.
7. **NEVER use HTML, CSS, SVG, React, JS, code drawing, code-based mockups or screenshots of coded UI to produce design.**
