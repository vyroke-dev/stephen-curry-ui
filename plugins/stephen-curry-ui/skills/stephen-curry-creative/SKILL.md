# Creative Direction Exploration

1. Confirm the brief, existing system, and any direction the user has already chosen. Do not restart a settled decision.
2. For a new site or broad redesign with meaningful creative freedom, develop at least three materially different concepts. Vary composition, narrative, hierarchy, and interaction grammar; color swaps alone do not count.
3. Show enough of the experience to judge the idea: entry, representative middle, ending, and relevant routes or states. Keep functional products clear and usable.
4. Label the evidence accurately. A written direction is not a high-fidelity visual. If visual tools are unavailable, provide the strongest permitted prototype and state which visual deliverable remains blocked.
5. Use a real independent jury for major work when the brief or release gate requires one. Otherwise use a proportionate critique and identify it accurately. Compare concepts only when the result can affect the choice.
6. Keep approved tokens and brand rules. Propose a versioned system change if the leading direction requires material exceptions.

For a focused change or user-selected direction, work within that direction and explore alternatives only when they add decision value. Use `../stephen-curry-ui/scripts/style_explorer.py` for the forms it supports; see `../stephen-curry-ui/references/creative-exploration.md`.
