# Visual exploration & design direction, without formulaic AI style

## Mandatory reference + fact gate

1. Inspect current repository, design/brand tokens, text/content, real product images/logos, access rights, past reference dossier and desired user journey. For time-sensitive product claims, verify with authoritative source before building or label unverified.
2. Research and capture **whole websites**, including middle, bottom, mobile navigation, route changes and significant states. Record the source URL, date, what was observed live vs inferred, and explicitly state what cannot be copied.
3. Write a one-sentence **earned thesis**: subject's own material/process/culture → audience experience and brand signal; avoid generic descriptions such as “premium gradients”. Name the primary user action or exploratory goal.
4. Try 2-3 deeply different creative concepts for flagship/high-uncertainty work. Each concept must differ in **composition**, **scene grammar**, **interaction mechanics**, **media behavior**, **mobile composition** and **ending**. Do not confuse 3 background colors with 3 directions.
5. Compare concepts in an interactive local design explorer, using the included [directions example](../templates/directions.example.json) as a schema and `scripts/style_explorer.py`. It is a rapid **comparison of visual logic**, not a substitute for full interaction prototypes or the final site.
6. Record one selected direction and at least one rejected direction with reasons. Ask for user approval for brand-critical expensive ambiguity, otherwise choose and document delegated rationale.

## The design must originate from content

Ask: What is this brand made of? What is surprising about its object/service/process? What proof do we show? What interaction could the user *meaningfully perform*? What is a credible visual metaphor? A strong signature persists into details, navigation, page exits and mobile without becoming a repetitive gimmick.

Avoid stereotypical AI defaults on autopilot (interchangeable gradient blob heroes, endless rounded cards, token glass overlays, all sections fade-up, empty statistic walls). **Do not ban any style categorically**: if truly contextually justified, use it well.

## Outcome artifacts

- `reference-dossier.md` with observed sources and uncertainty labels.
- `creative-directions.json` with 2-3 visually distinct options if flagship.
- `design-explorer.html`, generated by `style_explorer.py`; capture selection and user comments.
- `DESIGN.md` as the source of truth for art direction, responsive rules and motion grammar.

## Interaction and identity

At least one scene in an ambitious site should feel intentionally authored as an **experience**, not a decorative media placement. Build a proof-of-concept before the full site, then verify with mouse, keyboard, touch or accessibility fallback. Not every business website needs 3D; every site does need a credible point of view.
