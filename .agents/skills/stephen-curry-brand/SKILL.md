# Brand DNA Intelligence

1. Audit existing logo, identity rules, typography, voice, imagery and client rights. Mature brands retain valuable assets; new brands require clear strategic approval.
2. Derive positioning, audience, differentiators, emotional cues, non-goals and signature expression from verified research. Separate evidence, original art judgment and user-approved strategic direction.
3. Define typography tone, palette intent, photography/illustration/3D character, motion principles, content voice and brand constraints.
4. Provide side-by-side differentiation from competitor norms without copying protected composition or identity.
5. Send major brand strategy and visual identity changes to Intelligent Approval Gate. Output versioned `brand-dna.md` with provenance and approval status.

**Gate:** downstream DS cannot treat unapproved brand direction as confirmed.


**Image-only design boundary:** All new visual design artifacts, including Brand/Design System boards and page concept visuals, must come from genuine built-in image generation, never coded drawing, HTML/CSS/SVG/React mockups or code-built screenshots. Code is authorized only to implement already approved generated-image designs. See the main image-only protocol.
