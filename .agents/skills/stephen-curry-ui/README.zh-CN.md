# Stephen Curry UI 4.2 · 全部设计仅使用图片生成

## 硬性要求
**Design System 视觉板和网页设计图必须由真实可用的内置图像生成工具生成。禁止使用 HTML、CSS、React、SVG、Python、浏览器截图或任何代码生成设计。**

研究可以用文字；写代码仅用于把用户审批通过的设计图片实现成真实网站，不允许 code design 或 coded prototype 冒充设计。

必经流程：研究 → 7 张 Design System 图片板 → 图片评审及用户审批 → 3 套高保真网页设计图片（桌面/手机）→ 独立评审及用户审批 → 转换实现 tokens / React/CSS → 真实浏览器 QA。

图像工具不可用时必须停止设计并明确提示，不能降级成代码生成设计。Codex 登录 GPT 账户本身不保证图像工具接入。

本 Skill 与 Canvas 完全独立。独立 Agent、浏览器、图片生成能力均需实际检查，不得虚构可用性或通过结果。
